# 触觉传感器采购要求（Phase 5 选型清单）

> **已选定：洛城电子/冠拓电子 M0404S 串口版**（2026-09-08）。
> 16 点（4×4）压阻阵列 + 串口采集板；手册 3.4 节给出完整通信协议：
> 35 字节帧（0xAA 帧头 + 包号 + 16 点大端 16 位 + 累加和校验低 8 位），
> 115200 8N1 主动上报，SETB 指令可切 9600。解析器已按手册示例帧实现并
> 测试（`adapters/real_sensor/m0404s.py`）——到货即接 pyserial。
> 待确认：主动上报帧率（115200 带宽理论上限约 329 fps，实测为准）。
> 注意：必须买**串口版**（蓝牙版 Micro USB 仅充电）；手册"256 个感应点"
> 为复制错误，实际 16 点。

目标：v0.1 只需要"能跑通 live 循环"（record → replay → inference）的一块传感器。
按下面的硬性要求筛选/问客服，全部满足即可下单，价格越低越好；
加分项有则更好，没有不阻塞。

## 硬性要求（不满足就不买）

1. **输出接口**：USB 虚拟串口（CDC）或 USB-TTL（CH340 / CP2102 / FT232，macOS 免驱）。
   不买：仅蓝牙、需要专用接收卡的封闭方案、只给 Windows 上位机且无协议文档的方案。
2. **已知串口参数 + 帧格式**：波特率明确（如 115200），且有帧格式文档或解析例程
   （STM32/51/Arduino 代码即可——帧结构全在代码里）。
3. **连续输出模式**：上电即持续输出帧流；纯"请求-应答"触发模式不可用。
4. **帧率 ≥ 30 Hz**（slip 检测的底线，≥100 Hz 更好）——这是下单前必须问清的参数。
5. **矩阵/多区输出**：至少 4 个感应区，输出为数值（ADC 值或克数均可，
   非线性没关系，v0.1 只做相对值演示）。
6. **7 天无理由退货**（踩坑保险）。

## 加分项（有更好，没有不阻塞）

- macOS 免驱（CH340 / CP2102 / FT232 均免驱）；
- 提供上位机软件或协议手册截图；
- 扫描帧率可配置；
- 标称量程信息（用于把 ADC 值粗略换算成力值，仅展示用）。

## 价格锚点（2026-09 拼多多行情）

- 裸薄膜矩阵（4×4 / 4×8，FPC 接口）：¥30–70，需配采集板；
- 串口采集板（含扫描电路）：¥50–150；
- 整套（传感器 + 串口控制器）：¥100–150 合理；超过 ¥200 建议比价再买。
- 候选：洛城电子 M0404S 套装（串口版约 ¥293，偏贵但省心）；
  维可思 FS-ARR-4X8 裸膜（¥62）+ 同店采集板组合。

## 下单前问客服的三个问题

1. 扫描帧率多少 Hz？是否支持连续输出？
2. 串口帧格式文档或解析例程（要代码）？
3. USB 是虚拟串口（CDC）还是需要 USB-TTL 转接？Mac 能否免驱？

## 到货后的验收路径（对应仓库能力）

1. `pyserial` 连上后先看字节流 → 按"两"的帧格式解析成帧；
2. 写 `adapters/real_sensor`：每帧 → `TactileObservation`（`taxels` + 时间戳，
   用 `--calibration-id` 记录标定来源）；
3. 跑 `dataset quality` 同款指标做 live 健康检查（monotonic / dt jitter / nonfinite）；
4. 接 `model run contact / slip` 出事件 → `replay --viewer` 实时可视化；
5. 连续运行 30 分钟不崩 + p95 延迟可测 = Phase 5 DoD。
